How to read the numbers
Relative return: the published adjusted-price return minus SPY’s return for the same trading-day window. The unit is percentage points (pp), not dollars or investor flows.
Theme basket: an equal-weight arithmetic average of available stock returns. ETF/ETP proxies are excluded. This is a descriptive, fixed starting-weight basket return, not a backtested, daily-rebalanced portfolio.
Breadth: the number of available tracked stocks ahead of SPY divided by available tracked stocks. The denominator is shown. This is not the whole AI or Bitcoin market.
RVOL: latest session volume divided by the preceding 20-session average, excluding that latest session. A negative day with RVOL ≥ 1.50x is listed as a condition to check, not a sell instruction.
Data limits: only same-date observations are used. Incomplete source measurements remain N/A. MA60, candle history, trend duration, live research agents and personal holdings are not supplied by this snapshot.
Fund flows: price/volume strength does not establish net buying. The existing Market overview retains the separate ARTY and IBIT net-issuance estimates and their source requirements.
Implementation: an independent static-site adaptation inspired by the workflow of easy-stock. No upstream application code, model service or desktop runtime is bundled here.
